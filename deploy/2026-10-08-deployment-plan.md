# AI Mall 生产部署计划

目标：在 Oracle Oracle 上新增独立 AI Mall 服务，以 HTTPS aimall.novo.ccwu.cc 访问，并替换个人主页仓库按钮。

执行方式：本会话顺序执行，不派生代理；不修改既有网站业务数据。

1. [x] 检查仓库、资源、网络及生产安全配置；先复现迁移重复、默认账号和密码日志问题。
2. [x] 修复迁移版本冲突、移除公开默认密码和密码日志、限制 CORS；补充生产 Compose/Nginx 和回归测试。
3. [x] 服务器拉取远程代码，在独立目录应用本地部署补丁；生成强随机密钥，权限 600，独立数据库/数据卷，仅前端绑定回环端口 18100。
4. [x] 构建及运行镜像，内部部署 Ollama 模型，不使用本地 API 密钥，不新增付费云模型调用。验证商品浏览、账号注册登录、权限、AI SSE。
5. [x] 为域名签发 HTTPS 证书并配置续期，校验安全路径拒绝与旧站仍正常。
6. [x] 主页先添加失败测试，再将 AI Mall GitHub 按钮替换为经验证的公开地址，浏览器检查实际页面。

回滚：移除新增 aimall Nginx 配置并 reload，停止独立 aimall-prod 容器（不得加 -v）；保留数据卷和密钥。尚未上线前不替换主页链接。

验收：九个容器健康；HTTPS 页面及商品、注册登录/角色防越权、管理员后台、AI SSE 通过；151 项 AI 单元测试、88 项前端测试、15 项后端相关测试、10 项生产配置测试、13 项主页测试通过。域名证书续期 dry-run 成功。曾补充的 IP 备用入口现已按本人要求移除；仅保留域名。CPU AI 首次响应约 46–60 秒。残余 setuptools 平台特定构建告警记录于 README.production.md，不宣称零漏洞。
