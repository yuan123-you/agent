# Pinduoduo-style Cart Implementation Plan

**Goal:** Compact Pinduoduo-inspired cart, keeping cart APIs and existing brand.
**Architecture:** In-place Vue SFC, scoped tokens, existing /order/confirm checkout route.
**Tech Stack:** Vue 3, Element Plus, Vitest, Vite.
**Spec:** User requested Pinduoduo as the cart reference.

## Constraints
Only CartView.vue, CartView.spec.ts, isolated frontend/tests/cart.html and cart.ts browser fixtures, and this record. No backend, global theme, routes, dependencies or unrelated changes. No fictional discounts or delivery promises. Mobile checkout above navigation, desktop at viewport bottom.
