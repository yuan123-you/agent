# AI Mall 平台服务规则知识库

本知识库为 AI Mall 智能电商平台官方服务规则，涵盖商品、订单、物流、退换货、售后维权等全部核心规则，供智能客服与人工客服统一引用。

## 当前演示操作边界（优先于下述一般政策说明）

- 当前项目使用模拟支付，不调用银行、钱包、支付网关或承运商接口。退款仅更新演示记录，`refundMode=SIMULATED`，退款凭证以 `SIM-` 开头，不代表真实资金到账。
- 售后需要商家或平台显式人工审核，不会因超时自动同意。仅退款审核通过进入 `WAITING_REFUND`；退货退款还须登记寄回物流、由操作人员确认收货，之后再由授权操作人员执行模拟退款。批准申请不等于退款完成。
- 换货仅限原商品、原 SKU，不支持跨商品换货、不支持跨 SKU 换货或补退差价。退回商品已确认收货但无法发出换货时，买家可转为退款申请，仍须操作人员执行模拟退款。
- 当前演示不配置统一七天或十五天售后期限。七天无理由等消费者权益说明须核实适用条件，由人工结合适用法律、商品性质和有效承诺处理；不据此自动批准或拒绝申请，也不以演示能力限制减损依法享有的权益。
- 不承诺运费险赔付、上门取件或加急真实资金退款。下述维修、物流及费用责任说明属于有条件的政策背景，不表示演示已接入相关外部服务；需人工核实，不能把协商、审批或模拟记录说成实际赔付。本文不提供法律意见或统一法律期限。

3. 客服口头承诺若与书面规则冲突，以书面规则为准；客服超越权限的承诺不构成平台义务。

### 1.4平台术语解释

- **签收日**：物流系统显示签收的当日，含他人代收、快递柜签收、驿站签收。
- **自然日**：含周末及法定节假日，不因节假日顺延。
- **工作日**：不含周末及法定节假日。
- **商品完好**：商品本体无使用痕迹、无损坏，原包装、配件、吊牌、说明书、赠品齐全。
- **质量问题**：商品本身存在不符合国家标准、行业标准或商品描述的缺陷，非人为因素导致。
- **商家责任**：因商家原因导致的问题，包括但不限于质量问题、错发、漏发、描述不符、虚假宣传。
- **用户原因**：因用户个人选择导致的问题，包括但不限于不喜欢、尺码不合适、买错、多拍。

## 二、商品相关规则

### 2.1商品信息与描述1. 商品图片为专业拍摄，因显示器、光线等原因可能存在合理色差，合理色差不属于质量问题。
2. 商品参数、规格、材质、尺寸以商品详情页"规格参数"标注为准；手工测量存在 ±2cm 误差属于正常范围。
3. 商品详情页标注的"预计效果""参考图""示意图"不构成对实际效果的承诺。
4. 商品库存实时变动，下单后若遇缺货，商家应在24小时内通知用户并协商退款或换货。
5. 商品标题、主图、详情页描述不一致时，以对用户更有利的描述为准，但用户明知或应知的除外。
6. 商品的产地、发货地、生产日期等信息以商品详情页规格参数展示为准。

### 2.2商品价格1. 商品价格以下单时页面显示价格为准，下单后价格变动不补差价。
2. 平台商品标价即为到手价（含运费，全站包邮）。
3. 因系统故障导致的异常低价订单，平台有权取消并退款，不承担额外赔偿责任。
4. 商品销量、评价等信息实时更新，以商品详情页当前展示为准。

## 三、订单与支付规则

### 3.1下单与订单状态1. 下单成功以系统生成订单编号（SO 开头）为准，订单状态包括：待支付、已支付、已发货、已送达、已取消。
2. 未支付订单建议在24小时内完成支付；超时未支付可能导致库存释放、无法发货。
3. 支持单商品直接购买和购物车多商品合并结算；购物车结算生成一个订单、多个商品明细。
4. 订单生成后，商品价格锁定，不受后续价格变动影响。
5. 订单来源分为页面下单与 AI 助手代下单，二者具有同等效力。

### 3.2支付说明1. 平台演示环境使用模拟支付：提交订单后点击"去支付"即完成付款，订单状态实时更新为"已支付"。
2. 支付完成后商家安排发货；管理员/商家在后台执行发货操作并录入物流单号。
3. 请勿通过任何私人账户转账，所有交易必须在平台内完成。

### 3.3订单修改与取消

| 订单状态 | 可操作 | 说明 |
| --- | --- | --- |
| 待支付 | 取消订单 | 直接取消，无费用，库存即时回补 |
| 已支付未发货 | 不能直接取消 | 可申请仅退款，经人工审核后由授权操作人员执行模拟退款；申请不取消订单 |

## 四、物流配送规则

### 4.1发货时效

| 商品类型 | 发货时效 | 起算时间 |
| --- | --- | --- |
| 普通现货商品 | 48小时内 | 支付成功后 |
| 定制商品 | 以详情页标注为准（通常7-15天） | 确认设计稿后 |
| 大件家具家电 | 72小时内联系配送 | 支付成功后 |
| 生鲜商品 | 当日/次日达 | 以配送承诺为准 |

1. 发货时效指商家将商品交付物流公司的时间，非送达时间。
2. 遇不可抗力（自然灾害、疫情、交通管制等）导致延迟发货，商家应及时通知，不承担违约责任。
3. 商家超时未发货，用户可联系客服申请退款。

### 4.2物流查询与异常1. 商家发货后，订单详情页展示物流单号；送达时间以物流公司实际配送为准。
2. 物流异常类型及处理：
   - **长时间无更新**（超过72小时）：联系客服催促物流公司，必要时按丢件处理。
   - **显示签收但未收到**：先核实快递柜、驿站、门卫、家人代收；确认未收到可申请丢件理赔。
   - **物流停滞**：超过5天无更新，可申请退款或补发。
3. 丢件处理：客服核实后，用户可选择补发或全额退款，无需用户承担费用。

### 4.3签收与验货1. 收件时建议当面开箱验货，检查外包装是否破损、商品是否完好、配件是否齐全。
2. 外包装明显破损可直接拒收，拒收后商家重新发货或退款。
3. 他人代收（门卫、驿站、快递柜、家人）视为本人签收，签收时间以物流记录为准。
4. 签收后发现商品破损/少件，需在24小时内提供开箱视频或照片申请售后，逾期难以举证。

### 4.4运费规则1. 平台商品全站包邮，标价即为到手价。
2. 售后退换货运费按责任划分：
   - 用户原因退货（7天无理由、不喜欢、买错）：退回运费由用户承担；
   - 商家责任退货（质量问题、错发漏发、描述不符）：来回运费由商家承担，用户垫付后凭快递面单报销。
3. 运费报销以实际支付运费为准，需提供快递面单照片；顺丰、EMS 等高价快递需提前与商家确认，未经同意使用的超额部分由用户承担。
4. 到付件商家有权拒收，用户需先垫付运费再申请报销。

## 五、退换货条款（核心规则）

### 5.1 七天无理由退货的条件性说明

1. **适用条件**：七天无理由退货是消费者权益政策概念，应结合适用法律、商品性质、商品完好情况和有效承诺核实，不是本演示对所有商品统一作出的承诺。
2. **期限核实**：当前演示不配置统一七天期限，不自行指定签收当日或次日为起算日。具体适用期限及计算方式由人工根据适用规则核实，不据此自动批准或拒绝售后。
3. **商品完好**：核对商品本体、配件、赠品、包装与合理查验情况；不能把拆封一概视为丧失权利。特殊商品的适用条件与例外需单独核实。
4. **质量问题**：不适用无理由退货不代表不能就质量、错发、漏发或描述不符申请售后。
5. **运费与金额**：费用责任须按适用规则和核实结果处理；模拟退款不得超过原订单对应商品及数量的实付分摊上限，优惠不能按原价退还。

### 5.2 质量问题与原商品、原 SKU 换货

1. **适用条件**：非人为质量问题可提交凭证申请售后，由人工审核；本演示不配置统一十五天免费换货承诺。依法适用的质量责任及质保权益仍需核实处理。
2. **举证要求**：提供故障照片、视频或检测资料，说明问题与订单商品的对应关系。
3. **运费责任**：根据核实的质量责任与有效承诺说明，不表示平台已提供保险或自动报销服务。
4. **换货范围**：仅更换原商品、原 SKU；不支持跨商品换货、不支持跨 SKU 换货，不办理补退差价。需要其他商品或规格时，可按适用流程申请退款后另行购买，不是一次换货操作。
5. **缺货处理**：退回商品已经确认收货而无法发出换货时，买家可将售后转为退款申请；金额按原实付分摊上限重新计算，由授权操作人员执行模拟退款。
6. **进度**：以售后实际状态和人工处理记录为准，不保证固定审核、发出或送达时限。

### 5.3质保维修规则1. **质保期限**：以商品详情页标注或国家三包规定为准，二者取较长者。国家三包：家电整机1年、主要部件3年；手机整机1年；电脑整机2年。
2. **质保范围**：非人为因素导致的质量故障，在质保期内免费维修。
3. **不在质保范围**：
   - 进水、摔落、挤压、外力损坏；
   - 自行拆机、改装、刷机、root；
   - 未按说明书使用导致的损坏；
   - 正常磨损、耗材（电池、耳机线、滤芯等）；
   - 不可抗力导致的损坏。
4. **维修流程**：用户联系客服提交维修申请 → 商家审核后提供维修地址 → 维修周期一般7-15个工作日 → 同一故障维修两次仍无法正常使用，可申请换货或退款。
5. **维修运费**：质保期内质量问题维修，运费由商家承担；人为损坏维修，运费及维修费由用户承担。

### 5.5 退货退款完整流程

1. **提交申请**：在订单售后入口或通过 AI 准备并由买家确认申请，提供商品、数量、原因及必要凭证。提交申请不取消订单，也不执行退款。
2. **人工审核**：商家或平台显式同意或拒绝；退货审批须提供退货地址。不会因超时自动同意，久未处理可联系人工客服请求平台跟进；拒绝后可按售后入口申诉。
3. **寄回商品**：审核通过进入 `WAITING_RETURN`，买家按审核人员提供的地址寄回，登记真实可核实的物流单号；平台不提供默认示例地址或上门取件承诺。
4. **确认收货**：登记寄回后进入 `RETURN_SHIPPED`，操作人员检查并确认收到退回商品后进入 `WAITING_REFUND`；有争议时保留凭证并由平台处理。
5. **执行模拟退款**：授权操作人员另行执行退款后才为 `REFUNDED`，记录 `refundMode=SIMULATED` 和 `SIM-` 凭证。不代表真实资金到账，不存在银行、微信、支付宝退款或加急到账渠道。

### 5.6 仅退款（不退货）规则

1. **适用场景**：已支付未发货订单可申请仅退款；已发货或已送达商品的错发、漏发、瑕疵等诉求需结合事实和当前可操作状态审核，不保证全额支持。
2. **订单取消边界**：待支付订单取消只关闭订单并回补库存，没有已付资金可退。已支付订单申请售后不等于取消或退款。
3. **审核与执行**：须人工审核，不会因超时自动同意；批准后进入 `WAITING_REFUND`，授权操作人员执行模拟退款后才完成。
4. **退款金额**：按申请数量及原实付分摊上限核定，扣除已结算或占用额度，不能统一按订单总价或任意补偿比例承诺。
5. **商品归属**：经审核确认不需退货时，商品可由买家保留；争议仍通过平台处理。

### 5.7 原商品、原 SKU 换货流程

1. 买家提交换货申请及凭证，由商家或平台人工审核；不承诺统一七天或十五天资格窗口。
2. 审核同意后由审核人员录入退货地址，进入 `WAITING_RETURN`；仅更换原商品、原 SKU。
3. 买家寄回并登记物流，进入 `RETURN_SHIPPED`；操作人员确认收货后进入 `WAITING_EXCHANGE`。
4. 操作人员检查原商品、原 SKU 状态及库存，发出替换商品并登记物流后进入 `EXCHANGE_SHIPPED`；不支持跨商品、不支持跨 SKU 或补退差价。
5. 买家确认收到替换商品后进入 `EXCHANGED`。已确认收到退回商品但无法发出换货时，买家可转退款申请，由操作人员执行模拟退款；不保证固定换货完成时间。

### 5.8退换货拒绝场景与处理

| 拒绝场景 | 处理方式 | 用户救济途径 |
| --- | --- | --- |
| 对售后期限或适用条件存在争议 | 人工核实适用法律、商品性质及有效承诺，不按未配置的统一7天/15天期限拒绝 | 可提供证据请求平台处理；质量问题另行核实 |
| 商品人为损坏 | 拒绝无理由退换 | 可申请付费维修 |
| 缺少配件/包装，影响二次销售 | 扣除相应费用后退款，或拒绝退货 | 申请平台介入仲裁 |
| 特殊商品无质量问题 | 拒绝无理由退换 | 确认是否属于质量问题 |
| 无法提供质量问题凭证 | 要求补充凭证，暂不处理 | 补充凭证后重新提交 |

### 5.9退款金额计算细则1. **全额退款**：实付金额全部退还（商家责任场景）。
2. **部分退款**：按协商比例或缺失商品金额退款。
3. **扣除费用场景**：商品损坏/缺件扣除配件费、维修费、折旧费；已使用商品按使用程度扣除折旧费（具体标准由平台核定）。
4. **合并订单退款**：多商品订单按原实付金额（含优惠分摊）及申请数量核定上限，扣除已退款及占用额度；不按当前价格或未优惠的商品原价退款。全部购买数量结算为退款后订单才标记为已退款。

## 六、售后维权与平台介入

### 6.1平台介入条件1. 用户与商家协商失败，商家拒绝售后申请；
2. 商家超时未处理售后申请（超过48小时）；
3. 商家收货后久未处理退款，可请求人工跟进，不自动批准或执行退款；
4. 双方对运费、退款金额、商品质量存在争议；
5. 商家存在虚假宣传、欺诈、恶意拒绝售后等行为。

### 6.2平台介入流程1. **申请介入**：联系人工客服说明情况并上传举证材料。
2. **平台受理**：平台客服1个工作日内受理，通知商家在24小时内提交反证材料。
3. **双方举证**：用户举证（商品问题照片/视频、聊天记录、物流凭证）；商家举证（发货凭证、质检报告、沟通记录）；平台可要求双方补充材料。
4. **平台仲裁**：平台根据双方举证与平台规则做出仲裁，一般1-3个工作日给出结果，复杂案件可延长至7个工作日。
5. **执行处理结论**：授权操作人员依据审核结论推进模拟退款或原商品、原 SKU 换货；拒绝须说明理由并保留记录。费用责任须人工核实，不表示已执行真实资金赔付。

| 运费争议 | 快递面单、运费支付截图 | 运费标准说明 |

### 6.4投诉渠道1. **平台内投诉**：AI 助手对话中发送"转人工"后向人工客服提交投诉。
2. **外部投诉**：如平台处理不满意，可向12315消费者投诉热线、市场监督管理部门投诉。
3. **法律途径**：涉及重大纠纷可向人民法院提起诉讼。

## 九、高频常见问答（FAQ）

### 9.1退换货类1. **怎么申请退货？** 联系 AI 购物助手或转人工客服发起退货退款，说明退货原因并上传凭证（如有）。审核通过后按提供的地址寄回商品，并登记退货物流单号。
2. **7天无理由从哪天开始算？** 七天无理由须核实适用条件；当前演示不配置统一七天期限，也不自行指定起算日。请由人工结合适用法律、商品性质与有效承诺核实，不能仅据此自动同意或拒绝售后，质量问题仍可提交凭证申请处理。
3. **商品拆封了还能7天无理由退货吗？** 需人工核实七天无理由的适用条件、商品性质、商品完好及合理查验情况，不能把拆封一概作为拒绝理由。演示不配置统一七天期限；质量问题、错发或描述不符仍可提交凭证申请售后。
4. **退货运费谁承担？** 个人原因与商家责任应区分，通常个人原因退货由买家承担、质量或错发等商家责任由商家承担合理运费，具体须人工按适用规则核实。请保留面单和凭证；责任说明不代表演示提供真实运费报销、运费险赔付或上门取件。
5. **商家一直不处理售后怎么办？** 售后须由商家或平台人工审核，不会因超时自动同意，也不会自动退款。请联系人工客服请求平台跟进；被拒绝后可按售后入口申诉，具体进度以处理记录为准。
6. **定制商品可以退货吗？** 定制类商品（刻字、定制尺寸、个性化印刷等）若无质量问题，不支持7天无理由退货；若存在质量问题或与约定不符，可提供凭证申请售后。
7. **退款多久能到账？** 本项目仅模拟支付与退款，不代表真实资金到账。人工审核通过只是进入后续流程；退货退款还须操作人员确认收货，再由授权操作人员执行模拟退款，才记录 refundMode=SIMULATED 和 SIM- 凭证。没有银行或钱包到账时间及加急承诺，请查看售后状态。
8. **收到货少件/错发怎么办？** 保留快递面单、开箱视频及商品照片，联系人工客服申请售后，由商家或平台审核责任与可执行方案。换货仅限原商品、原 SKU；退款须按原实付分摊上限由操作人员另行执行模拟退款，不保证自动补发或实际赔付。
9. **商品有质量问题怎么处理？** 提供故障照片或视频申请售后，由人工核实责任、适用法律与有效承诺；演示不配置统一十五天换货期限。换货仅限原商品、原 SKU；退款须由操作人员另行执行模拟退款，质保维修和运费责任需分别核实。
10. **可以只退款不退货吗？** 已支付未发货订单可申请仅退款；错发、漏发、瑕疵等情况须人工审核是否无需退货。取消待支付订单没有已付资金可退，提交申请不等于退款；批准后还须授权操作人员执行模拟退款。
11. **换货需要多久？** 需人工审核、买家寄回、操作人员确认收货，再检查原商品、原 SKU 库存并发出替换商品，买家确认收到后完成。以售后记录为准，不保证固定时限；已收回商品但无法发出时可由买家转退款申请，仍为模拟退款。
12. **使用过的商品可以退货吗？** 需人工按适用条件核实商品完好、合理查验与实际使用程度，不能把使用或未配置的统一七天期限一概作为拒绝理由。质量问题仍可提交凭证申请售后，按适用法律与有效承诺处理。
13. **生鲜食品收到坏了怎么办？** 发现变质或损坏请停止食用，尽快保留商品、包装及收货照片或视频，联系人工客服申请售后。鲜活易腐商品的无理由退货例外不排除质量问题权益；不设置本演示未配置的两小时拒绝期限。经人工审核及必要收货确认后，授权操作人员执行的仍是模拟退款。

### 9.2订单与支付类14. **订单可以修改地址吗？** 订单提交后暂不支持自助修改地址，请下单时准确填写收货信息；发货后无法修改，如地址填错可联系客服或拒收后重新下单。
15. **未支付订单多久失效？** 建议在24小时内完成支付，超时可能导致库存释放、无法正常发货；待支付订单可随时取消，库存即时回补。
16. **可以取消已发货的订单吗？** 已发货订单不能直接取消。可联系承运方协商拒收或签收后申请退货退款，但拒收不会自动批准售后或退款；仍须人工审核、必要收货确认及授权操作人员执行模拟退款。
17. **购物车结算和立即购买有什么区别？** 立即购买生成单商品订单；购物车可勾选多个商品合并结算，生成一个订单多个商品明细，任一商品库存不足时整单不成立。

### 9.3物流配送类18. **什么时候发货？** 普通现货商品支付成功后48小时内发货；定制商品以详情页标注时间为准。发货后可在订单详情页查看物流单号。
19. **物流一直不更新怎么办？** 物流信息由物流公司提供，可能存在数小时延迟。如超过72小时无更新，联系客服催促；超过5天无更新，可申请退款或补发。
20. **显示签收但我没收到货怎么办？** 先检查快递柜、驿站、门卫及家人代收情况，保留物流记录，仍未找到时联系人工客服核实责任与可行方案。不能仅凭签收状态承诺全额赔付或补发；适用退款须审核后由授权操作人员执行模拟退款。
21. **外包装破损可以拒收吗？** 外包装明显破损可先拍照留证并与配送人员沟通验货或拒收；已签收发现内件损坏也请尽快保留开箱证据并联系人工客服。拒收不自动批准售后，适用退款仍须人工审核、必要收货确认后执行模拟退款，不承诺自动重新发货。

### 9.4平台介入与投诉类22. **怎么申请平台介入？** 商家拒绝售后或超时未处理时，联系人工客服说明情况并上传举证材料（照片/视频/聊天记录/物流凭证），平台一般1-3个工作日给出仲裁结果。
23. **对平台处理结果不满意怎么办？** 可向12315消费者投诉热线或当地市场监督管理部门投诉，也可通过法律途径解决。
24. **商家卖假货怎么投诉？** 保留商品照片、鉴定资料及订单凭证，联系人工客服提交投诉，由平台核实责任和适用处理。依法享有的退款及赔偿权益不因演示限制而消失，但不能承诺本演示已执行真实赔偿；系统退款须按实付上限审核并另行执行模拟退款，其他救济需人工核实。

**换货能改成别的型号或 SKU 吗？** 不能。当前换货只更换原商品、原 SKU，不支持跨商品换货、不支持跨 SKU 换货或补退差价。需要其他商品或规格时，可按适用流程申请退款后另行购买。

**平台有运费险、上门取件或加急退款吗？** 当前演示不承诺运费险赔付、上门取件或加急退款。退款仅为模拟记录，不发生真实资金结算；退货地址由审核人员录入，运费责任需人工核实。
