# AI Mall 平台服务规则知识库

本知识库为 AI Mall 智能电商平台官方服务规则，涵盖商品、订单、物流、退换货、售后维权等全部核心规则，供智能客服与人工客服统一引用。

## 一、平台基础说明

### 1.1平台定位与服务范围1. AI Mall 是全品类智能电商平台，覆盖手机数码、电脑办公、家用电器、服饰内衣、美妆个护、食品生鲜、母婴玩具、运动户外、图书文娱、家具家居、珠宝饰品、箱包、鞋靴、宠物生活、医疗保健、汽车用品等16大品类。
2. 平台支持线上选购、在线下单（演示环境为模拟支付）、AI 智能客服咨询（7×24小时）、人工客服转接、商品评论、购物车、收藏与浏览历史等全链路服务。
3. 平台仅提供交易撮合与技术服务，商品由入驻商家直接销售并承担相应责任；平台自营商品由平台直接承担责任。

### 1.2服务时间与渠道

### 1.3规则效力说明1. 用户注册账号并下单，即视为已阅读并同意平台服务规则。
2. 平台有权根据法律法规及业务需要更新规则，更新后在平台公告区公示，公示期后生效。
3. 客服口头承诺若与书面规则冲突，以书面规则为准；客服超越权限的承诺不构成平台义务。

### 1.4平台术语解释

- **签收日**：物流系统显示签收的当日，含他人代收、快递柜签收、驿站签收。
- **自然日**：含周末及法定节假日，不因节假日顺延。
- **工作日**：不含周末及法定节假日。
- **商品完好**：商品本体无使用痕迹、无损坏，原包装、配件、吊牌、说明书、赠品齐全。
- **质量问题**：商品本身存在不符合国家标准、行业标准或商品描述的缺陷，非人为因素导致。
- **商家责任**：因商家原因导致的问题，包括但不限于质量问题、错发、漏发、描述不符、虚假宣传。
- **用户原因**：因用户个人选择导致的问题，包括但不限于不喜欢、尺码不合适、买错、多拍。

## 二、商品相关规则

### 2.1商品信息与描述1. 商品图片为专业拍摄，因显示器、光线等原因可能存在合理色差，合理色差不属于质量问题。
2. 商品参数、规格、材质、尺寸以商品详情页"规格参数"标注为准；手工测量存在 ±2cm 误差属于正常范围。
3. 商品详情页标注的"预计效果""参考图""示意图"不构成对实际效果的承诺。
4. 商品库存实时变动，下单后若遇缺货，商家应在24小时内通知用户并协商退款或换货。
5. 商品标题、主图、详情页描述不一致时，以对用户更有利的描述为准，但用户明知或应知的除外。
6. 商品的产地、发货地、生产日期等信息以商品详情页规格参数展示为准。

### 2.2商品价格1. 商品价格以下单时页面显示价格为准，下单后价格变动不补差价。
2. 平台商品标价即为到手价（含运费，全站包邮）。
3. 因系统故障导致的异常低价订单，平台有权取消并退款，不承担额外赔偿责任。
4. 商品销量、评价等信息实时更新，以商品详情页当前展示为准。

## 三、订单与支付规则

### 3.1下单与订单状态1. 下单成功以系统生成订单编号（SO 开头）为准，订单状态包括：待支付、已支付、已发货、已送达、已取消。
2. 未支付订单建议在24小时内完成支付；超时未支付可能导致库存释放、无法发货。
3. 支持单商品直接购买和购物车多商品合并结算；购物车结算生成一个订单、多个商品明细。
4. 订单生成后，商品价格锁定，不受后续价格变动影响。
5. 订单来源分为页面下单与 AI 助手代下单，二者具有同等效力。

### 3.2支付说明1. 平台演示环境使用模拟支付：提交订单后点击"去支付"即完成付款，订单状态实时更新为"已支付"。
2. 支付完成后商家安排发货；管理员/商家在后台执行发货操作并录入物流单号。
3. 请勿通过任何私人账户转账，所有交易必须在平台内完成。

### 3.3订单修改与取消

| 订单状态 | 可操作 | 说明 |

1. 下单时请准确填写收货人姓名、电话、地址；订单提交后暂不支持自助修改地址，发货后无法修改。

## 四、物流配送规则

### 4.1发货时效

| 商品类型 | 发货时效 | 起算时间 |
| --- | --- | --- |
| 普通现货商品 | 48小时内 | 支付成功后 |
| 定制商品 | 以详情页标注为准（通常7-15天） | 确认设计稿后 |
| 大件家具家电 | 72小时内联系配送 | 支付成功后 |
| 生鲜商品 | 当日/次日达 | 以配送承诺为准 |

1. 发货时效指商家将商品交付物流公司的时间，非送达时间。
2. 遇不可抗力（自然灾害、疫情、交通管制等）导致延迟发货，商家应及时通知，不承担违约责任。
3. 商家超时未发货，用户可联系客服申请退款。

### 4.2物流查询与异常1. 商家发货后，订单详情页展示物流单号；送达时间以物流公司实际配送为准。
2. 物流异常类型及处理：
   - **长时间无更新**（超过72小时）：联系客服催促物流公司，必要时按丢件处理。
   - **显示签收但未收到**：先核实快递柜、驿站、门卫、家人代收；确认未收到可申请丢件理赔。
   - **物流停滞**：超过5天无更新，可申请退款或补发。
3. 丢件处理：客服核实后，用户可选择补发或全额退款，无需用户承担费用。

### 4.3签收与验货1. 收件时建议当面开箱验货，检查外包装是否破损、商品是否完好、配件是否齐全。
2. 外包装明显破损可直接拒收，拒收后商家重新发货或退款。
3. 他人代收（门卫、驿站、快递柜、家人）视为本人签收，签收时间以物流记录为准。
4. 签收后发现商品破损/少件，需在24小时内提供开箱视频或照片申请售后，逾期难以举证。

### 4.4运费规则1. 平台商品全站包邮，标价即为到手价。
2. 售后退换货运费按责任划分：
   - 用户原因退货（7天无理由、不喜欢、买错）：退回运费由用户承担；
   - 商家责任退货（质量问题、错发漏发、描述不符）：来回运费由商家承担，用户垫付后凭快递面单报销。
3. 运费报销以实际支付运费为准，需提供快递面单照片；顺丰、EMS 等高价快递需提前与商家确认，未经同意使用的超额部分由用户承担。
4. 到付件商家有权拒收，用户需先垫付运费再申请报销。

## 五、退换货条款（核心规则）

### 5.17 天无理由退货规则1. **适用条件**：签收之日起7自然日内，商品完好，不影响二次销售，用户可申请无理由退货，无需说明理由。
2. **起算时间**：物流签收当日为第1天，第7天23:59:59前提交申请有效；周末和法定节假日包含在内，不顺延。
3. **商品完好标准**：
   - 商品本体无划痕、磕碰、污渍、磨损、洗涤、使用痕迹；
   - 原包装、吊牌、标签、配件、说明书、保修卡齐全；
   - 赠品（如有）一并退回；
   - 未自行拆卸、改装、激活、注册。
4. **不适用7天无理由的商品**：详见5.4不支持清单；此类商品若存在质量问题，仍可按质量问题售后规则处理。
5. **运费**：7天无理由属于用户个人原因，退回运费由用户承担。
6. **退款金额**：按实付金额退款。

### 5.215天质量问题换货规则1. **适用条件**：签收之日起15自然日内，商品出现非人为质量问题，支持免费换货。
2. **举证要求**：用户需提供故障照片、视频或检测报告，清晰展示质量问题。
3. **运费**：质量问题换货来回运费均由商家承担。
4. **换货处理**：
   - 同型号有货：发出同型号全新商品；
   - 同型号缺货：用户可选择更换等价其他型号，或申请全额退款；
   - 差价处理：更换高价型号需补差价，更换低价型号退还差价。
5. **换货时效**：商家收到退回商品后48小时内发出新商品，特殊商品以约定为准。

### 5.3质保维修规则1. **质保期限**：以商品详情页标注或国家三包规定为准，二者取较长者。国家三包：家电整机1年、主要部件3年；手机整机1年；电脑整机2年。
2. **质保范围**：非人为因素导致的质量故障，在质保期内免费维修。
3. **不在质保范围**：
   - 进水、摔落、挤压、外力损坏；
   - 自行拆机、改装、刷机、root；
   - 未按说明书使用导致的损坏；
   - 正常磨损、耗材（电池、耳机线、滤芯等）；
   - 不可抗力导致的损坏。
4. **维修流程**：用户联系客服提交维修申请 → 商家审核后提供维修地址 → 维修周期一般7-15个工作日 → 同一故障维修两次仍无法正常使用，可申请换货或退款。
5. **维修运费**：质保期内质量问题维修，运费由商家承担；人为损坏维修，运费及维修费由用户承担。

### 5.5退货退款完整流程1. **第1步·提交申请**：联系 AI 购物助手或转人工客服发起退货退款；说明退货原因（必选）、问题描述，质量问题需提供凭证（照片/视频）。
2. **第2步·商家审核**：商家48小时内处理（同意/拒绝/要求补充凭证）；商家超时未处理，系统自动同意退货申请；商家拒绝后用户可要求平台介入。
3. **第3步·寄回商品**：审核通过后获取退货地址；用户自行联系快递寄回（到付件商家有权拒收）；商家签收前可撤回退货申请。
4. **第4步·收货核验**：商家签收退货后48小时内核验商品；核验通过执行退款；核验不通过（商品损坏/缺件）则拒绝退款并上传凭证，用户可申请平台介入。
5. **第5步·退款到账**：退款原路退回至支付账户；模拟支付订单退款即时生效，真实渠道一般1-7个工作日到账；退款金额等于实付金额减去应扣除费用（如有）。

### 5.6仅退款（不退货）规则1. **适用场景**：
   - 未发货订单：取消订单即全额退款，无需退货；
   - 商家错发、漏发：用户选择不退货，申请部分退款补偿；
   - 商品轻微瑕疵：用户选择保留商品，申请部分退款；
   - 商品已损坏无法退回：经核实后申请全额退款。
2. **审核时效**：商家48小时内审核，超时系统自动同意。
3. **退款金额**：未发货全额退款；错发漏发按缺失商品对应金额退款；轻微瑕疵双方协商，一般为订单金额的10%-50%。
4. **商品归属**：仅退款不退货的商品归用户所有，商家不得要求退回。

### 5.7换货完整流程1. **第1步**：联系 AI 助手或人工客服申请换货，填写换货原因、上传凭证（质量问题必填），注明期望更换的型号/规格。
2. **第2步**：商家48小时内审核；同意后提供退货地址并确认新商品型号。
3. **第3步**：用户寄回旧商品并登记物流单号；质量问题运费商家报销，个人原因运费用户承担。
4. **第4步**：商家收到旧件后48小时内核验；核验通过发出新商品并同步新物流单号；核验不通过则拒绝换货并退回旧商品。
5. **第5步**：用户签收新商品验货确认，换货完成；新商品享受正常质保，质保期重新计算。

### 5.8退换货拒绝场景与处理

| 拒绝场景 | 处理方式 | 用户救济途径 |
| --- | --- | --- |
| 超过售后时效（7天/15天/质保期） | 拒绝退换 | 质量问题隐蔽的可申请平台特殊处理 |
| 商品人为损坏 | 拒绝无理由退换 | 可申请付费维修 |
| 缺少配件/包装，影响二次销售 | 扣除相应费用后退款，或拒绝退货 | 申请平台介入仲裁 |
| 特殊商品无质量问题 | 拒绝无理由退换 | 确认是否属于质量问题 |
| 无法提供质量问题凭证 | 要求补充凭证，暂不处理 | 补充凭证后重新提交 |
| 退回商品与原订单不符 | 拒绝退款，退回商品 | 核实物流，快递错发可申诉 |

### 5.9退款金额计算细则1. **全额退款**：实付金额全部退还（商家责任场景）。
2. **部分退款**：按协商比例或缺失商品金额退款。
3. **扣除费用场景**：商品损坏/缺件扣除配件费、维修费、折旧费；已使用商品按使用程度扣除折旧费（具体标准由平台核定）。
4. **合并订单退款**：购物车多商品订单部分退货时，按对应商品明细金额退款，其余商品不受影响。

## 六、售后维权与平台介入

### 6.1平台介入条件1. 用户与商家协商失败，商家拒绝售后申请；
2. 商家超时未处理售后申请（超过48小时）；
3. 商家收货后超时未退款（超过48小时）；
4. 双方对运费、退款金额、商品质量存在争议；
5. 商家存在虚假宣传、欺诈、恶意拒绝售后等行为。

### 6.2平台介入流程1. **申请介入**：联系人工客服说明情况并上传举证材料。
2. **平台受理**：平台客服1个工作日内受理，通知商家在24小时内提交反证材料。
3. **双方举证**：用户举证（商品问题照片/视频、聊天记录、物流凭证）；商家举证（发货凭证、质检报告、沟通记录）；平台可要求双方补充材料。
4. **平台仲裁**：平台根据双方举证与平台规则做出仲裁，一般1-3个工作日给出结果，复杂案件可延长至7个工作日。
5. **执行仲裁**：支持用户则强制商家退款/换货/承担运费；支持商家则驳回申请并说明理由；双方均有责任则按责任比例分担。

### 6.3举证材料清单

| 争议类型 | 用户需提供 | 商家需提供 |
| --- | --- | --- |
| 质量问题 | 故障照片/视频、开箱视频、检测报告 | 出厂质检报告、发货前验货记录 |
| 错发漏发 | 开箱视频、商品照片、快递面单 | 发货称重记录、拣货记录 |
| 描述不符 | 商品实物与详情页对比图 | 商品参数证明、供应商资质 |
| 物流问题 | 物流截图、签收凭证、开箱视频 | 发货凭证、物流公司证明 |
| 运费争议 | 快递面单、运费支付截图 | 运费标准说明 |

### 6.4投诉渠道1. **平台内投诉**：AI 助手对话中发送"转人工"后向人工客服提交投诉。
2. **外部投诉**：如平台处理不满意，可向12315消费者投诉热线、市场监督管理部门投诉。
3. **法律途径**：涉及重大纠纷可向人民法院提起诉讼。

## 七、账户与安全规则

### 7.1账户注册与安全1. 注册需使用唯一用户名，账号密码应设置高强度密码。
2. 账号仅限本人使用，禁止转让、出租、售卖账号。
3. 因用户泄露密码导致的账户损失，由用户自行承担。
4. 账号被盗应立即联系客服冻结并修改密码。
5. 平台角色分为买家、商家、人工客服、管理员，权限相互隔离；请妥善保管自己的账号凭证。

### 7.2商家账号说明1. 商家通过"商家中心"上架商品，商品基础信息（商品名、品牌、类目、价格、库存、商品简介、商品图片）为必填项，材质、产地、发货地、生产日期等为选填项。
2. 商家对上架商品的描述真实性负责，虚假宣传将按违规规则处理。
3. 商家可在商家中心管理商品上下架、库存与价格，并回复商品评论。

## 八、违规处理规则

## 九、高频常见问答（FAQ）

### 9.1退换货类1. **怎么申请退货？** 联系 AI 购物助手或转人工客服发起退货退款，说明退货原因并上传凭证（如有）。审核通过后按提供的地址寄回商品，并登记退货物流单号。
2. **7天无理由从哪天开始算？** 从物流签收当日开始计算，第1天为签收日，第7天23:59:59前提交申请均有效。周末和法定节假日包含在内，不顺延。
3. **商品拆封了还能7天无理由退货吗？** 普通商品拆封后只要商品完好、不影响二次销售，可以申请7天无理由退货。但贴身用品、美妆、已激活数码设备、图书等特殊商品，拆封后不支持7天无理由（质量问题除外）。
4. **退货运费谁承担？** 个人原因退货（7天无理由、买错、不喜欢），运费由您承担；商家责任退货（质量问题、错发漏发），运费由商家承担，您垫付后凭快递面单申请报销。
5. **商家一直不处理售后怎么办？** 商家48小时未处理售后申请，系统会自动同意您的申请；若商家拒绝，您可要求平台介入仲裁。
6. **定制商品可以退货吗？** 定制类商品（刻字、定制尺寸、个性化印刷等）若无质量问题，不支持7天无理由退货；若存在质量问题或与约定不符，可提供凭证申请售后。
7. **退款多久能到账？** 商家审核通过并确认收货后，退款原路退回支付账户。模拟支付订单退款即时生效；真实渠道微信/支付宝一般1-3个工作日，银行卡3-7个工作日。
8. **收到货少件/错发怎么办？** 请提供开箱视频或照片（含快递面单和商品全貌），联系客服或 AI 助手反馈。核实后可补发缺失商品、更换错发商品，或按对应金额退款，来回运费由商家承担。
9. **商品有质量问题怎么处理？** 签收15日内可申请免费换货或退货退款；超过15日在质保期内可申请免费维修。请提供故障照片或视频作为凭证，质量问题运费由商家承担。
10. **可以只退款不退货吗？** 以下情况可申请仅退款：未发货订单（取消订单）、商家错发漏发您选择不退货、商品轻微瑕疵您选择保留、商品已损坏无法退回。
11. **换货需要多久？** 商家收到寄回商品后48小时内核验，核验通过后发出新商品；加上物流时间一般7-10个工作日完成换货。
12. **使用过的商品可以退货吗？** 7天无理由退货要求商品完好、不影响二次销售，有明显使用痕迹的商品无法无理由退货；若商品存在质量问题，即使使用过也可以申请质量问题售后。
13. **生鲜食品收到坏了怎么办？** 生鲜食品不支持7天无理由，但签收时发现变质、损坏，请在2小时内提供开箱照片/视频联系客服，核实后可按比例退款或补发。

### 9.2订单与支付类14. **订单可以修改地址吗？** 订单提交后暂不支持自助修改地址，请下单时准确填写收货信息；发货后无法修改，如地址填错可联系客服或拒收后重新下单。
15. **未支付订单多久失效？** 建议在24小时内完成支付，超时可能导致库存释放、无法正常发货；待支付订单可随时取消，库存即时回补。
16. **可以取消已发货的订单吗？** 已发货订单无法直接取消，您可以选择拒收（快递退回后商家退款），或签收后申请退货退款。
17. **购物车结算和立即购买有什么区别？** 立即购买生成单商品订单；购物车可勾选多个商品合并结算，生成一个订单多个商品明细，任一商品库存不足时整单不成立。

### 9.3物流配送类18. **什么时候发货？** 普通现货商品支付成功后48小时内发货；定制商品以详情页标注时间为准。发货后可在订单详情页查看物流单号。
19. **物流一直不更新怎么办？** 物流信息由物流公司提供，可能存在数小时延迟。如超过72小时无更新，联系客服催促；超过5天无更新，可申请退款或补发。
20. **显示签收但我没收到货怎么办？** 先检查快递柜、驿站、门卫、家人是否代收；确认未收到后联系客服，平台核实后按丢件处理，可补发或全额退款。
21. **外包装破损可以拒收吗？** 可以。外包装明显破损时建议直接拒收，拒收后商家会重新发货或退款；如已签收，发现内件损坏请在24小时内提供开箱照片申请售后。

### 9.4平台介入与投诉类22. **怎么申请平台介入？** 商家拒绝售后或超时未处理时，联系人工客服说明情况并上传举证材料（照片/视频/聊天记录/物流凭证），平台一般1-3个工作日给出仲裁结果。
23. **对平台处理结果不满意怎么办？** 可向12315消费者投诉热线或当地市场监督管理部门投诉，也可通过法律途径解决。
24. **商家卖假货怎么投诉？** 提供商品照片、鉴定报告等证据，联系人工客服提交投诉；平台核实后会下架商品、处罚商家，并为您办理退款赔偿。
