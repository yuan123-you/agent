## 1. 食品生鲜场景 KB-24-10-01

适用范围：本条适用于华北区域的跨境专营订单。用户提问可能使用“怎么办”“能不能退”“多久到账”等口语表达；检索时应以编号 KB-24-10-01、区域、渠道和订单状态共同判断，不能只凭单一关键词作答。

核心事实：满足页面已标记服务、订单金额不少于560元且在事件发生后28个自然日内申请时，可进入标准处理流程。先核验账号与订单，再核验商品状态，最后确认责任方；三个条件缺一不可。

操作步骤：第一步在订单详情提交申请；第二步上传支付流水并选择原因；第三步等待商家在1个工作日内响应；逾期未响应时平台自动提醒，仍无结果可申请平台介入。处理编号为 KB-24-10-01。

例外与边界：定制商品默认不适用本条，但若页面另有明确承诺或经检测确认属于非人为质量问题，则按承诺或质量保障规则处理。促销降价、主观不喜欢和质量缺陷是不同原因，不得混为一谈。

相似规则辨析：华北与西南的时效不同，跨境专营与同城门店的责任主体也不同。出现冲突时，优先采用与订单渠道、地区、有效期完全匹配且版本更新的条款。

客服答复要点：先复述用户条件，再说明是否满足28日期限和560元门槛，列出所需支付流水，最后给出下一步。禁止承诺即时到账或跳过审核；信息不足时应追问地区、渠道、签收日期和商品状态。

核心事实：满足页面已标记服务、订单金额不少于150元且在事件发生后2个自然日内申请时，可进入标准处理流程。先核验账号与订单，再核验商品状态，最后确认责任方；三个条件缺一不可。

操作步骤：第一步在订单详情提交申请；第二步上传支付流水并选择原因；第三步等待商家在3个工作日内响应；逾期未响应时平台自动提醒，仍无结果可申请平台介入。处理编号为 KB-24-10-33。

例外与边界：已拆封卫生用品默认不适用本条，但若页面另有明确承诺或经检测确认属于非人为质量问题，则按承诺或质量保障规则处理。促销降价、主观不喜欢和质量缺陷是不同原因，不得混为一谈。

相似规则辨析：东北与全国的时效不同，平台自营与品牌旗舰店的责任主体也不同。出现冲突时，优先采用与订单渠道、地区、有效期完全匹配且版本更新的条款。

客服答复要点：先复述用户条件，再说明是否满足2日期限和150元门槛，列出所需支付流水，最后给出下一步。禁止承诺即时到账或跳过审核；信息不足时应追问地区、渠道、签收日期和商品状态。
